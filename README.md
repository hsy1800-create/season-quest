# 계절 탐사대 23.5

6학년 2학기 과학 **1. 계절의 변화 8~9차시 「계절 변화의 원인을 찾아라!」**(교과서 24~27쪽, 실험관찰 16~17쪽)를
모둠이 교과서를 읽으며 해결하는 미션형 웹앱입니다. 교사용 실시간 현황판이 함께 있습니다.

## 주소

- 학생 앱: <https://hsy1800-create.github.io/season-quest/> (현황판의 QR로 들어오면 방 코드가 자동 입력)
- Firebase 프로젝트: `season-quest` (Realtime Database, 싱가포르) — 연결 완료

## 수업에서 쓰는 법

1. 교사: 교사 현황판 주소를 열고 **새 방 만들기**를 누릅니다.
2. 화면의 **QR 코드**나 **방 코드**를 학생들에게 보여 줍니다.
3. 모둠: QR로 접속하면 방 코드가 자동으로 들어갑니다. 시작 방법은 두 가지입니다.
   - **각자 패드로 (추천)**: 모둠장이 **모둠 만들기**로 모둠 이름·모둠원·역할 선잇기를 하고 '나는 누구예요?'에서 자기 이름을 고릅니다.
     나머지 친구는 **우리 모둠 들어가기** → 모둠 → 내 이름을 누릅니다.
     모든 패드에 같은 화면이 실시간으로 뜨고, 단계마다 그 역할을 맡은 친구 패드에서만 누를 수 있습니다.
     (읽기 대장: 미션 시작 → 기록 대장: 답 고르기 → 모두: 자기 패드에서 동의 → 확인 대장: 정답 확인 → 발표 대장: 설명 후 다음)
     결석하거나 패드가 꺼진 친구는 동의에서 빠지고, 그 친구의 역할은 접속한 누구나 대신할 수 있습니다.
   - **패드 한 대로**: 인터넷이 불안하거나 패드가 모자랄 때, 지금까지처럼 한 대로 합니다.
4. 현황판에서 모둠별 진행, 점수, 오답, 멈춘 모둠을 실시간으로 봅니다.
   - **관문 대기**(미션 4)가 뜨면 발표 대장의 설명을 듣고 **관문 통과**를 누릅니다.
   - **전체 알림**으로 "5분 남았어요" 같은 메시지를 모든 모둠 화면에 띄웁니다.
   - **순위판(TV용)** 탭은 점수 순위를 크게 보여 줍니다.
   - **우리 반이 많이 틀린 문제**를 보고 수업 중간에 다시 짚어 줄 수 있습니다.
5. 다음 반 수업은 **방 바꾸기 → 새 방 만들기**로 새 방에서 시작합니다.

> Firebase를 연결하지 않아도 학생 앱은 각 기기에서 따로 동작합니다(현황판만 안 됨).
> 이때 미션 4 관문은 선생님 코드(처음 값 `2350`)를 입력해 통과합니다.

## Firebase 연결하기 (처음 한 번, 약 10분)

GitHub Pages는 파일만 보여 주는 곳이라 기기끼리 데이터를 주고받을 수 없습니다.
그래서 모둠 기기 → 교사 현황판으로 진행 상황을 모으는 데 Firebase **Realtime Database**(무료 Spark 요금제)를 씁니다.

1. <https://console.firebase.google.com> 에 구글 계정으로 로그인 → **프로젝트 추가**
   - 이름 예: `season-quest` / Google 애널리틱스는 **사용 안 함**
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: **싱가포르(asia-southeast1)** / **잠금 모드로 시작**
3. Realtime Database의 **규칙** 탭 → 내용을 모두 지우고 `database.rules.json` 내용을 붙여 넣기 → **게시**
4. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`)** 아이콘
   - 앱 닉네임 예: `season-quest-web` / Firebase 호스팅은 체크하지 않음
   - 나오는 `firebaseConfig = { ... }` 의 `{ ... }` 부분을 복사
5. `firebase-config.js` 의 `window.FIREBASE_CONFIG = null;` 을
   `window.FIREBASE_CONFIG = { ...복사한 내용... };` 으로 바꾸고 저장 → GitHub에 올리기
   - `databaseURL` 줄이 있는지 꼭 확인하세요.

웹용 Firebase 설정값(apiKey 등)은 비밀번호가 아니라 "어느 프로젝트에 연결할지"를 알려 주는 주소라서 공개 저장소에 올라가도 괜찮습니다.
데이터 보호는 3번의 보안 규칙이 맡습니다.

### 무료 사용량
Spark(무료) 요금제: 동시 접속 100개, 저장 1GB, 월 10GB 전송. 한 학급 수업에는 충분합니다.

### 알아 둘 점
- 로그인 없이 쓰는 구조라서, 방 코드와 `teacher.html` 주소를 아는 사람은 현황판을 열 수 있습니다.
  학생에게는 `teacher.html` 주소를 알려 주지 마세요.
- 학생 이름이 Firebase에 저장됩니다. 필요하면 모둠원 이름을 별명이나 번호로 쓰게 하세요.
  수업이 끝나면 현황판의 **방 초기화**로 기록을 지울 수 있습니다.

## GitHub Pages로 공개하기

1. 이 폴더를 GitHub 저장소(`season-quest`)에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch** / Branch: **main**, 폴더 **/(root)** → Save
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/season-quest/` 에서 열립니다.

## 문제 고치기

`missions.js` 에 미션 6개와 문제가 들어 있습니다. 문제 유형:
`blanks`(빈칸 낱말 카드), `sort`(두 갈래 분류), `choice`(객관식), `multi`(여러 개 고르기), `ox`,
`order`(순서 맞추기), `match`(용어-뜻 잇기), `nums`(숫자 입력), `grid`(실험관찰 표), `sim`(모형실험 시뮬레이터),
`checkpoint`(선생님 관문), `write`(서술형 결론).
